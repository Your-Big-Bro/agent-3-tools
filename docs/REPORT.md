# Отчёт по проекту «Агент с 3 tools»

**Автор:** Dimanowski
**Репозиторий:** `agent-3-tools`
**Дата:** ноябрь 2026

---

## 1. Что требовалось

Реализовать агента, который в зависимости от запроса пользователя переключается на нужный инструмент
(минимум три), с обязательным логированием выбора инструмента, памятью диалога и трейсингом.
Дополнительно - упаковать в Docker.

---

## 2. Что сделано

| Пункт | Как реализовано | Где смотреть |
|---|---|---|
| Три инструмента | `calculator`, `now`, `lookup` | `app/tools/` |
| Выбор инструмента агентом | ReAct-агент LangGraph (Ollama) + детерминированный mock-роутер | `app/agent.py`, `app/router_mock.py` |
| Логирование выбора | консоль + `logs/runs.jsonl` (поле `tool`) | `app/logging_setup.py` |
| Память диалога | SQLite-история + чекпоинтер LangGraph, сессии по `--session` | `app/memory.py` |
| Трейсинг | LangSmith через переменные окружения | `app/tracing.py` |
| Docker | `Dockerfile`, `docker-compose.yml`, `.dockerignore` | корень проекта |
| Тесты | 62 теста без сети и модели | `tests/` |
| Двуязычные промпты | ru/en комплекты, переключение `PROMPT_LANG` и `--lang` | `app/prompts.py` |

---

## 3. Как проверить за три минуты

```bash
# 1. Демонстрационный сценарий (7 запросов, без установки зависимостей)
python -m app --demo

# 2. Тесты
python -m unittest discover -s tests -t . -v

# 3. Журнал запусков
python -m app --log
```

В выводе `--demo` видно, что на разные вопросы выбираются разные инструменты:

```
[1/7] Сколько будет 125 * 12?                → tool=calculator
[2/7] Какое сегодня число и день недели?     → tool=now
[3/7] На каком стеке сделан этот проект?     → tool=lookup
[4/7] Меня зовут Дима, запомни это.          → без инструмента (память)
[5/7] Как меня зовут?                        → без инструмента, ответ «Дима» (память)
[6/7] Посчитай (15 + 27) * 3                 → tool=calculator
[7/7] Что такое Docker в этом проекте?       → tool=lookup
```

Память показана не «мета-вопросом», а обычной репликой: имя, названное на шаге 4, воспроизводится на шаге 5
из истории диалога (SQLite + чекпоинтер LangGraph).

## 4. Доказательства выполнения требований

**Выбор инструмента.** Каждая запись в `logs/runs.jsonl` содержит поля `question`, `tool`, `tool_args`,
`tool_result`, `duration_ms`. Консольная строка начинается с `tool=<имя>`.

**Память.** Вопрос «Что я спрашивал раньше?» отвечает списком предыдущих вопросов этой же сессии,
что видно в демо-сценарии (шаг 4).

**Трейсинг.** При заданном `LANGSMITH_API_KEY` каждый запуск появляется в проекте `agent-3-tools`
на smith.langchain.com. Скриншоты - в `docs/screenshots/`.

**Docker.** `docker build -t agent-3-tools .` и `docker run --rm agent-3-tools --demo`.

Результаты проверки:

| Проверка | Результат |
|---|---|
| `docker build -t agent-3-tools .` | образ 278 МБ, сборка ~25 с |
| `docker run --rm agent-3-tools --demo` | 7/7 запросов, mock-режим, код возврата 0 |
| `docker compose run --rm app --demo` | 7/7 запросов, LLM-режим через Ollama на хосте, код возврата 0 |

## 5. Что можно улучшить

- Добавить инструмент с внешним API (погода/курсы), чтобы показать работу агента с сетью.
- Перевести чекпоинтер на Postgres и приложить compose-профиль как основной вариант.
- Расширить базу знаний `lookup`, добавить эмбеддинги для семантического поиска.
